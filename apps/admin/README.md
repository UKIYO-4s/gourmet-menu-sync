# Admin App

Astro-based admin UI skeleton for Menu Sync System.

## Scope

- Internal MVP admin shell only
- React islands may be added only where interaction requires them
- No external site admin screen analysis
- No Chrome extension real connection
- No auto save, auto publish, or auto delete

## Commands

```sh
pnpm --filter @menusync/admin dev
pnpm --filter @menusync/admin build
pnpm --filter @menusync/admin typecheck
```

## 決めたこと

- ADR-004 の方針（Mapping JSON のホット更新 / 任意コード実行禁止 / required_extension_version 強制）を Phase 1.5 検証の前提とする
- 実画面検証では値そのもの（input value）を扱わず、構造情報・hash・score のみを観察対象とする
- 検証段階では実装コードを書かない。観察と記録のみ
- Hotpepper実画面DOMは未確認のため、mapping sample の selector / URL pattern / store identity signal は `provisional` として扱う
- DB論理スキーマはPostgreSQL寄りで復旧し、将来D1へ移行する場合は `JSONB` をTEXT JSONへ置換する前提を明記する
- `auto_submit_enabled=false` / `submit.autoSubmit=false` は、mapping sample とDB制約の両方で維持する

## 検証時の禁止事項（再掲）

- ログイン情報 / Cookie / Session / Token を保存しない
- 生DOM全文 / outerHTML を保存しない

- 保存ボタン・公開ボタン・削除ボタンを押さない
